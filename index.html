PIWavelet

Modern Python library for Continuous Wavelet Transform, Cross Wavelet Transform and Wavelet Coherence Analysis.

Pure Python implementation inspired by Torrence & Compo (1998) and Grinsted et al. (2004).

Overview

PIWavelet provides modern wavelet analysis tools for scientific computing, signal processing, geophysics, climatology, neuroscience and time-frequency analysis.

The library includes:

  • Continuous Wavelet Transform (CWT)
  • Cross Wavelet Transform (XWT)
  • Wavelet Coherence (WTC)
  • Statistical significance testing
  • AR(1) red-noise modeling
  • Torrence-Webster smoothing operators
  • Cone of Influence (COI)
  • Phase-angle visualization
  • Morlet, Paul, DOG and Mexican Hat wavelets
  • Modern matplotlib visualization utilities

Installation


pip install piwavelet

Or install directly from GitHub: 


pip install git+https://github.com/duducosmos/PIWavelet.git

Main Features

Feature Description
Continuous Wavelet Transform Time-frequency decomposition using scalable mother wavelets.
Wavelet Coherence Localized correlation analysis between two time series.
Cross Wavelet Power Joint power spectrum between signals.
Statistical Significance AR(1)-based significance testing following Torrence & Compo.
Phase Arrows Relative phase relationship visualization.
COI Masking Cone of influence visualization for edge-effect interpretation.

Wavelet Coherence Example


import numpy as np

from piwavelet.transforms import wavelet_coherence
from piwavelet.plotting import plot_wavelet_coherence

dt = 0.25

time = np.arange(0, 512) * dt

x = np.sin(2 * np.pi * time / 16)

y = np.zeros_like(time)

mask = (time > 40) & (time < 80)

y[mask] = np.sin(
    2 * np.pi * (time[mask] - 2) / 16
)

x += 0.5 * np.random.randn(len(time))
y += 0.5 * np.random.randn(len(time))

result = wavelet_coherence(
    x,
    y,
    dt=dt,
)

fig = plot_wavelet_coherence(
    result,
    title="Wavelet Coherence",
    units="days",
    show_phase=True,
)

fig.show()

Statistical Significance

PIWavelet implements statistical significance tests based on:

  • AR(1) red-noise background spectra
  • Pointwise significance
  • Time-averaged significance
  • Scale-averaged significance

Following:

Torrence & Compo (1998) and Grinsted et al. (2004).
